# FLORA — Brand System v1

## 1. Brand core

**Nombre:** FLORA
**Tagline principal:** Inteligencia para el campo
**Tagline alternativo:** Visión inteligente para la salud vegetal

### Propuesta de valor
FLORA ayuda a interpretar visualmente el estado de hojas de cultivo mediante clasificación asistida por inteligencia artificial.

### Personalidad
- Profesional
- Confiable
- Clara
- Tecnológica
- Orgánica
- Premium
- Contemporánea

### Qué NO debe parecer
- No infantil
- No genérica
- No “template SaaS” sin personalidad
- No excesivamente científica/fría
- No futurista exagerada
- No agro tradicional anticuada

---

## 2. Creative direction

FLORA combina dos universos:

### Naturaleza
- Salud vegetal
- Agricultura
- Campo
- Materia orgánica
- Observación biológica

### Tecnología
- Inteligencia artificial
- Visión computacional
- Clasificación
- Escaneo
- Precisión
- Diagnóstico asistido

### Síntesis buscada
Una estética agritech premium con base orgánica, interfaz limpia y detalles sutiles inspirados en escaneo holográfico.

## 4. Typography

### Rol visual
La tipografía debe transmitir claridad, tecnología y confianza, pero sin perder calidez.

### Recomendación
- Headings: Outfit
- Body/UI: DM Sans

### Criterios
- Titulares sólidos
- Muy buena legibilidad en desktop y mobile
- Sensación de producto moderno
- Compatible con interfaz técnica y branding

## 5. Logo direction

### Idea general
El isotipo de FLORA debe unir:
- hoja
- visión / escaneo
- tecnología

### Posibles caminos
1. **Leaf + Lens**
   - Una hoja simplificada integrada con un lente o apertura visual.

2. **Leaf + Scan**
   - Hoja geométrica con líneas de escaneo o grid sutil.

3. **Leaf + Signal**
   - Una hoja con un pulso o halo que represente lectura inteligente.

### Requisitos
- Debe funcionar en tamaños pequeños
- Debe servir para app, favicon y avatar
- Debe verse bien en monocromo
- Debe sentirse contemporáneo y premium

## 8. Future premium experience

### Objetivo
Crear una versión premium del frontend con una pieza central 3D.

### Pieza hero
Una papa 3D holográfica / agritech que:
- flote suavemente
- rote lentamente
- reaccione al análisis
- reaccione a la categoría predicha sin atribuir una severidad no medida

### Stack futuro
- Next.js
- React
- Three.js / React Three Fiber
- Backend actual de Cloud Run reutilizado

### Reacción visual del modelo
- Estado inicial: holograma con rotación suave.
- Analizando: escaneo, pulsos de luz y movimiento reactivo.
- Healthy: representación visual estable.
- Fungi, Pest, Virus y otras clases: efectos visuales diferenciados por categoría.
- La confianza del modelo NO representa severidad de enfermedad.
- La severidad solo podrá visualizarse cuantitativamente cuando exista un modelo específico validado.
- La papa holográfica es una metáfora visual: el clasificador actual analiza hojas, no tubérculos.
